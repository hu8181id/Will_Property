# Panduan Hosting Gratis Tanpa Kartu Kredit untuk Website Statis Primedeal

Karena Render meminta verifikasi kartu kredit untuk pembuatan service baru, berikut adalah pilihan platform hosting statis 100% gratis yang **tidak memerlukan kartu kredit sama sekali**, sangat cocok untuk repositori GitHub `hu8181id/Will_Property`:

## 1. Vercel (Direkomendasikan)
- **Biaya:** Gratis selamanya untuk Personal Use.
- **Kartu Kredit:** Tidak diperlukan.
- **Kelebihan:** Integrasi GitHub sangat mulus, performa global luar biasa, otomatis mendukung HTTPS dan custom domain gratis.
- **Cara Penggunaan:**
  1. Buka [vercel.com](https://vercel.com) dan login dengan akun GitHub Anda.
  2. Klik **Add New → Project**.
  3. Impor repository `Will_Property`.
  4. Biarkan pengaturan default (Build Command kosong, Output Directory `.`).
  5. Klik **Deploy**.

## 2. Netlify
- **Biaya:** Gratis pada paket Starter.
- **Kartu Kredit:** Tidak diperlukan.
- **Kelebihan:** Sangat mudah untuk menghubungkan repository GitHub tanpa verifikasi kartu.
- **Cara Penggunaan:**
  1. Buka [netlify.com](https://netlify.com) dan login dengan GitHub.
  2. Pilih **Add new site → Import an existing project**.
  3. Pilih GitHub dan pilih repository `Will_Property`.
  4. Klik **Deploy site**.

## 3. GitHub Pages
- **Biaya:** Gratis selamanya.
- **Kartu Kredit:** Tidak diperlukan.
- **Kelebihan:** Langsung melekat pada repository GitHub Anda tanpa registrasi layanan tambahan.
- **Cara Penggunaan:**
  1. Masuk ke repository GitHub `hu8181id/Will_Property`.
  2. Masuk ke **Settings → Pages**.
  3. Pada bagian Build and deployment, pilih Branch `main` dan folder `/ (root)`.
  4. Klik **Save**.
